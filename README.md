# ALVÉRA Company Profile Website

Website profil perusahaan ALVÉRA dibuat dengan HTML, CSS, dan JavaScript terpisah.

## Struktur file
- `index.html` — halaman Home
- `about.html` — halaman About Us
- `style.css` — styling dan responsive layout
- `script.js` — menu mobile dan tahun footer

## Menjalankan di VS Code
1. Ekstrak ZIP ini ke folder kerja.
2. Buka folder `alvera-company-profile` di VS Code.
3. Buka `index.html` di browser, atau gunakan ekstensi Live Server untuk pengalaman pengembangan yang lebih nyaman.
4. Pastikan koneksi internet tersedia untuk Google Fonts dan gambar Unsplash.

## Catatan
Tautan kontak menggunakan contoh email `hello@alvera.studio`. Ganti dengan alamat email resmi sebelum dipublikasikan. Foto dimuat dari Unsplash sehingga membutuhkan koneksi internet.
